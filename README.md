A high-performance, glassmorphic technical portfolio built for **Kodurupaka Kumara Anurag**, AI/ML Engineer at Vangrove Tech Private Limited.

---

## 🌟 Key Features

- **Live macOS JSON Terminal (`anurag_profile.json`)**: Interactive candidate profile with syntax highlighting, telemetry tags, and 1-click clipboard copy.
- **Interactive AI & Machine Learning Sandbox**: Real simulated endpoints (`/api/v1/rag-retrieval`, `/api/v1/model-inference`, `/api/v1/data-pipeline`, `/api/v1/candidate-match`) with realistic latency and dynamic JSON inspectors.
- **Technical Skills Matrix**: Filterable grid across Generative AI, Machine Learning, Programming, and Database technologies with real-time search and animated proficiency progress bars.
- **Featured Systems & Deep Case Studies**: Multi-tab modal views covering System Architecture, SLA metrics, and live sandbox links.
- **Curriculum Vitae Modal**: Clean, recruitment-standard printable resume with PDF print and download actions.
- **Dark / Light Mode**: Seamless theme switching with high-contrast, accessibility-tested palette tokens.
- **Real-Time Indian Standard Time (IST) Clock**: Live ticking clock in the footer synced to Hyderabad, India.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kodurupakakumaraanurag-png/AI_RESUME_PORTFOLIO.git
   cd AI_RESUME_PORTFOLIO
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
